# Season Scope (네이버 데이터랩 쇼핑인사이트 스크래퍼)

네이버 데이터랩 쇼핑인사이트를 활용하여 최신 데이터 동향 분석을 위한 인기 검색어(TOP 500) 데이터를 자동으로 수집하고 분석하는 프로젝트입니다. 특히 1차 산물(식품) 위주의 시장 트렌드를 파악하는 데 특화되어 있습니다.

## 🎯 주요 기능
- **자동화 데이터 수집**: 식품 카테고리(축산물, 수산물, 농산물>과일, 농산물>채소)의 TOP 500 인기 검색어를 자동 스크래핑합니다.
- **주 단위 트렌드 비교**: 가장 최근에 끝난 주(월~일)를 기준으로 7개 주간 데이터를 수집하여, 올해 흐름과 작년 같은 시기 이후 4주의 흐름을 비교합니다.

  | 용도 | 기간 (2026-10-12 실행 예시) |
  |---|---|
  | 올해 이번 주 | 2026-10-05 ~ 10-11 (가장 최근에 끝난 주) |
  | 올해 지난주 | 2026-09-28 ~ 10-04 |
  | 작년 같은 주 | 2025-10-06 ~ 10-12 (기준 주의 52주 전, 요일 일치) |
  | 작년 +1주 ~ +4주 | 2025-10-13 ~ 11-09 |
- **타겟 연령층 설정**: 구매력이 높은 40대, 50대, 60대 이상의 데이터를 집중적으로 수집합니다.
- **결과물 자동 정리**: 카테고리 4개 × 기간 7개 = 28개 CSV가 `results/실행일/카테고리_시작일_종료일.csv` 형식(예: `과일_2025-10-13_2025-10-19.csv`)으로 저장됩니다. 전체 수집에 약 30분이 소요됩니다.
- **대시보드 UI**: Streamlit을 활용하여 사용자가 직접 편리하게 실행할 수 있는 웹 UI를 제공합니다.

## 🛠️ 기술 스택
- **Language**: Python 3.x
- **Web Scraping**: Playwright
- **Data Processing**: Pandas
- **UI**: Streamlit
- **Automation**: GitHub Actions

## 🚀 설치 및 실행 방법

### 1. 대시보드 실행 (권장)
- **Mac**: `run_dashboard.command` 더블클릭
- **Windows**: `run_dashboard.bat` 더블클릭

실행 스크립트가 가상환경(`.venv`) 생성, 패키지 설치, 스크래핑용 브라우저(Chromium) 설치를 자동으로 처리한 뒤 대시보드를 엽니다.

### 2. 수집만 바로 실행 (UI 없이)
```bash
# Mac
.venv/bin/python scraper_main.py
# Windows
.venv\Scripts\python.exe scraper_main.py
```
수집 대상 중 하나라도 실패하면 종료 코드 1을 반환하며, 실패 원인은 `logs/scraper_YYYY-MM-DD.log`에 기록됩니다.

## 📁 프로젝트 구조
- `app.py`: Streamlit 기반 웹 UI 대시보드
- `scraper_main.py`: 네이버 데이터랩 크롤링 메인 로직
- `date_utils.py`: 주 단위 수집 기간 7개 산출
- `results/`: 수집된 CSV 데이터가 실행 일자별로 저장되는 디렉토리
- `logs/`: 실행 일자별 수집 로그
- `reports/`: 과거에 생성된 분석 보고서 보관 (보고서 자동 생성 기능은 제거됨)
- `docs/`: 프로젝트 기획서 및 프롬프트 등 관련 문서 보관

## ⏱️ 자동화 스케줄링
GitHub Actions(`.github/workflows/scraper_schedule.yml`)를 통해 매주 토요일 새벽 4시(KST)에 정기적으로 자동 수집 파이프라인이 동작하도록 구성되어 있습니다.
